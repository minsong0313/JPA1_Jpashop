# Spring boot와 Jpa를 활용한 도서 구매 웹 사이트
## Abstract
Java Spring과 JPA를 사용하여 개발된 온라인 쇼핑 플래폼 입니다.

## 기술 스택
- Java
- Spring Framework
- JPA/Hibernate
- H2 Database

## 주요 기능
#### 1. 회원 기능
- 회원 등록
- 회원 조회

#### 2. 상품 기능
- 상품 등록
- 상품 수정
- 상품 조회

#### 3. 주문 기능
- 상품 주문
- 주문 내역 조회
- 주문 취소
